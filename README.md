# Python Chapter 6 — Conditional Statements

This repository contains my practice programs and exercises from **Python Chapter 6**. This chapter focuses on making decisions in Python programs using conditional statements.

## Topics Covered

### 1. `if` Statement

Learn how to use the `if` statement to execute a block of code when a specified condition is true.

Example:

```python
if condition:
    # code to execute
```

### 2. `if-else` Statement

Learn how to use `if-else` to choose between two possible blocks of code based on a condition.

Example:

```python
if condition:
    # code if condition is true
else:
    # code if condition is false
```

### 3. `if-elif-else` Statement

Learn how to check multiple conditions using `elif`.

Example:

```python
if condition1:
    # code
elif condition2:
    # code
else:
    # code
```

### 4. `if-elif` Ladder

Practice using an `if-elif` ladder to evaluate multiple conditions in sequence.

The conditions are checked from top to bottom, and the appropriate block is executed when a condition is satisfied.

### 5. Multiple `if` Statements

Learn the difference between multiple independent `if` statements and an `if-elif-else` structure.

Example:

```python
if condition1:
    # code

if condition2:
    # code

if condition3:
    # code
```

Each `if` statement is evaluated independently.
